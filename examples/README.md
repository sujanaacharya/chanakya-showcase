# Sample report

`javaseclab-report.md` is the unedited output of `chanakya analyze` with AI turned off (`--no-ai`), run on JavaSecLab, a public Java application that is vulnerable on purpose and is used for teaching. The only change I made is replacing my local folder path with the project name.

This is raw tool output. I have not hand-checked each finding in this run. Some flagged methods are named `safe...` in the demo app, and some of those may be false positives. The report also lists the cases the tool could not decide, under "Unresolved", instead of calling them safe.
